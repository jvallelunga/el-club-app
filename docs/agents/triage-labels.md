# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                                       |
| -------------------------- | -------------------- | ------------------------------------------------------------- |
| `needs-triage`             | `backlog`            | Idea not evaluated or specified yet                           |
| `needs-info`               | `refinement`         | Being refined: information is still being completed           |
| `ready-for-agent`          | `ready`              | Fully specified, ready for the agent to develop               |
| `ready-for-human`          | `manual`             | Has to be done by a person (DNS, Supabase, keys…), not code   |
| `wontfix`                  | `wontfix`            | Will not be actioned                                          |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

`in progress` and `done` are part of this repo's flow (see `docs/agents/issue-tracker.md`) but are not triage roles.
