# Frames

Acá viven los frames de baja fidelidad, agrupados por feature (por ejemplo `docs/frames/roles-y-permisos/`).

Un frame muestra estructura y flujo: pantallas, navegación, qué datos entran y qué pasa después. No define estética (colores finales, tipografías, componentes pulidos). Eso va en los mocks de UI, que Claude arma a partir del frame y del issue, y Jerónimo aprueba en el PR antes de implementar.

El issue de la feature debería linkear el frame. Si no hay frame, no lo inventes: preguntá en el issue.
