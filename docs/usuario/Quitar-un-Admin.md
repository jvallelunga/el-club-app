# Quitar un Admin

Un Admin del club puede quitar a los otros Admins de tu club. A vos mismo no te podés quitar.

1. En el menú, entrá a **Admins**.
2. En la persona que querés sacar, tocá **Quitar**.
3. Confirmá con **Quitar**.

La persona deja de ser Admin de tu club. Si la volvés a agregar, vuelve a serlo.

- Al lado de tu nombre no aparece **Quitar**: un Admin no se puede quitar a sí mismo. Si querés dejar de ser Admin, pedíselo a otro Admin de tu club.
